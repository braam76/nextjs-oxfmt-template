# Inboxer Frontend

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). The home route starts blank; edit `app/page.tsx` to build it.

## Code checks

- `pnpm lint` runs Oxlint.
- `pnpm format` formats files with Oxfmt.
- `pnpm format:check` checks formatting without changing files.
